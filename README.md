# Notes_min
Это десктопное приложение "Умные заметки", представляющее собой простой менеджер записей.

Программа позволяет:

создавать, редактировать и удалять текстовые заметки;
прикреплять к заметкам ключевые слова (теги);
искать нужные записи по этим тегам.

Все данные (текст заметок и их теги) автоматически сохраняются в локальный файл notes_data.json, поэтому информация не теряется после закрытия программы. Интерфейс состоит из списка заметок, поля для ввода текста, списка тегов и панели управления с кнопками.
